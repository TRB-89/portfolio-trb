## 1. Deployment Architecture

The application is architected as a high-performance, single-page application (SPA) optimized for edge delivery on Vercel's global CDN:

- **Build Output:** Static HTML, JavaScript, CSS, and asset bundles generated in `dist/`.
- **Bundle Strategy:** Explicit manual chunking via Rollup:
  - `three` (`three`, `@react-three/fiber`, `@react-three/drei`, `@react-three/rapier`): Physics and WebGL engine (~501 kB).
  - `r3f` / `Lanyard`: Dynamic lazy-loaded 3D badge bundle (~211 kB + ~26 kB).
  - `motion`: Framer Motion runtime chunk (~173 kB).
  - `icons`: Lucide React icon suite chunk (~31 kB).
  - `FlexCarousel`: React Bits dynamic showcase component (~78 kB).
  - `index`: Core application runtime, metadata, and sections (~427 kB).
- **Routing & Rewrites:** Configured in `vercel.json` with single-page application rewrite rule (`"source": "/(.*)", "destination": "/index.html"`).
- **Asset Caching Policy:**
  - Hashed static assets (`dist/assets/*`): `Cache-Control: public, max-age=31536000, immutable`.
  - Application HTML (`/index.html`): `Cache-Control: public, max-age=0, must-revalidate` to ensure immediate propagation of releases without stale cache traps.

## 3. Deployment Runbook

### Step 1: Branch Verification & Sync
```bash
git checkout feat/portfolio-v2
git status
git fetch origin
git log origin/main..HEAD --oneline
```
Ensure that no unreviewed changes exist and `origin/main` commits are fully integrated.

### Step 2: Local Quality Gate Execution
Run the full static suite and build:
```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
```

### Step 3: Regression Suite Execution
Execute all 7 regression specifications sequentially using single-worker allocation:
```bash
npx playwright test tests/foundation.spec.ts --workers=1 --retries=0
npx playwright test tests/navigation-interactions.spec.ts --workers=1 --retries=0
npx playwright test tests/about-lanyard.spec.ts --workers=1 --retries=0
npx playwright test tests/projects-showcase.spec.ts --workers=1 --retries=0
npx playwright test tests/case-studies-scrollstack.spec.ts --workers=1 --retries=0
npx playwright test tests/techstack-achievements.spec.ts --workers=1 --retries=0
npx playwright test tests/phase08-refinement.spec.ts --workers=1 --retries=0
```

### Step 4: Commit & Push Release Candidate
```bash
git add .
git commit -m "chore(release): prepare portfolio v2 release candidate"
git push -u origin feat/portfolio-v2
```

### Step 5: Create Pull Request (Draft)
Create a draft pull request against `main` for team / owner visual inspection:
```bash
gh pr create --base main --head feat/portfolio-v2 --title "feat(release): portfolio v2 — beyond the interface" --body-file docs/RELEASE_PR_BODY.md --draft
```

### Step 6: Vercel Preview Verification
1. Open the preview deployment generated by Vercel for `feat/portfolio-v2`.
2. Inspect live behavior across Chrome, Safari, Firefox, and mobile viewport.
3. Validate:
   - WebGL shaders (LiquidChrome, Lanyard 3D physics badge).
   - React Bits components (18/18 active).
   - Navigation (StaggeredMenu, SocialDock).
   - Project showcase (FlexCarousel expanding panels, 3D reel toggle).
   - Case studies (ScrollStack sequential layering, pipeline diagrams).
   - Milestones (CountUp counters, AnimatedList selection).
   - Contact form actions and copy protocols.
   - Reduced-motion accessibility mode.

### Step 7: Production Promotion Gate (Mandatory Human Sign-Off)
> [!IMPORTANT]
> Merging to `main` and deploying to production is gated on explicit human approval from Tarun R.
> **DO NOT** execute production deployment or auto-merge until written confirmation is received.

When approved:
```bash
# 1. Merge PR or fast-forward merge
gh pr merge --squash --delete-branch
# or locally:
git checkout main
git merge --ff-only feat/portfolio-v2
git push origin main

# 2. Vercel automatically deploys main to production:
# Monitor deployment:
vercel --prod
```

## 5. Post-Deployment Smoke Test Protocol

Immediately following promotion to `https://portfoliotrb.vercel.app/`:

1. **HTTP Status:** Verify `200 OK` on root URL.
2. **SEO & Social Cards:** Verify OpenGraph tags and Twitter meta cards using social debugger tools.
3. **Console Hygiene:** Confirm zero runtime exceptions or WebGL context failures in browser developer tools.
4. **Link Integrity:** Confirm all outbound links open in new tabs with `rel="noopener noreferrer"`.
5. **AURA Live Verification:** Confirm the AURA link routes correctly to `https://aura-umber-eight-10.vercel.app/`.
6. **Mobile Touch:** Confirm no horizontal layout shift or scroll trapping occurs on mobile screens.
